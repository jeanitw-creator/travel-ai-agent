# CCI｜旅行社獲客網站

依本課程定義，將旅客面臨的選擇困難轉為網站的產品要求。

| CCI | 本課程定義 | 網站如何做到 | 如何檢查 |
| --- | --- | --- | --- |
| Core 核心 | 幫助旅客快速找到適合自己的旅遊行程。 | 從週報進入偏好表單，送出後顯示最多三個可比較方案，每個方案附推薦理由與來源。 | 旅客從首頁可進入表單、查看結果並回到原條件修改。 |
| Clear 明確 | 可選旅遊對象、預算、天數、旅遊風格。 | 提供親子、情侶、熟齡三類旅遊對象。預算標示為全團新臺幣上限，天數以日為單位，風格可複選。另詢問人數、到訪日及必要限制，以利比對。 | 表單可完成四項選擇，結果頁重述條件。預算不足或日期不符時，旅客看得到原因。 |
| Issue 問題 | 行程太多、比較困難、不知道如何選擇。 | 先篩必要條件，再依風格與偏好排序。結果使用相同欄位呈現天數、費用、行程亮點及待確認事項。 | 不符條件的方案不列入正式推薦。零筆結果時可保留原條件、調整指定欄位或複製諮詢摘要。 |

## 週報如何引導旅客

- 親子從街屋、工藝或動物觀察選主題，表單再詢問孩子的興趣及可連續步行時間。
- 情侶從湖畔騎行或海景攝影選主題，表單再詢問兩人想要的活動強度。
- 熟齡旅客從看展或賞花選主題，表單再詢問休息需求及必要的友善設施。

首頁的客群入口只預填旅遊對象與可編輯的風格。週報素材如何對應表單與行程條件，見 PRD 的「週報素材對應」。景點特色沿用原研究來源，價格、場次與通行條件依資料狀態顯示。 [台灣旅遊情報週報](weekly-report.md) · [來源清單](../research/sources.md) · [產品需求](PRD.md)

結果以全團、全程的新臺幣總額比較。若目前沒有符合的方案，旅客可保留原條件、查看原因並自行調整，也可複製諮詢摘要。過期情報在週報標示有效截止日供回顧，待確認資訊在受影響欄位旁說明查證進度。

## 第一版的衡量方式

在驗收時觀察三類旅客能否自行完成「週報進入表單 → 看懂推薦理由 → 修改偏好或取得諮詢摘要」。這是使用情境驗收，第一版未設置線上轉換追蹤。 [流程分工](SIPOC.md) · [產品需求與驗收](PRD.md)
